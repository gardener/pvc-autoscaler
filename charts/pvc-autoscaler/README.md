# pvc-autoscaler

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![Type: application](https://img.shields.io/badge/Type-application-informational?style=flat-square) ![AppVersion: v0.3.2](https://img.shields.io/badge/AppVersion-v0.3.2-informational?style=flat-square)

A Helm chart for pvc-autoscaler, a Kubernetes controller which resizes persistent volumes when their available space or inodes drop below a threshold

## Prerequisites

- A storage class with `allowVolumeExpansion: true`
- A Prometheus compatible API that exposes the `kubelet_volume_stats_*` metrics
- [cert-manager](https://cert-manager.io/) for the webhook certificate, unless `webhook.certManager.enabled` is `false` and `webhook.tls` is set

## Installing the Chart

```shell
helm install pvc-autoscaler ./charts/pvc-autoscaler \
  --namespace pvc-autoscaler-system \
  --create-namespace \
  --set prometheus.address=http://prometheus.monitoring.svc:9090
```

The CRD is rendered from `templates/` so that `helm upgrade` updates it. It carries `helm.sh/resource-policy: keep` by default, so `helm uninstall` does not delete existing `PersistentVolumeClaimAutoscaler` resources.

## Development

`files/crds/` and `files/rbac/role.yaml` are copies of the controller-gen output in `config/`, and this README is generated by [helm-docs](https://github.com/norwoodj/helm-docs). Run `make generate` to update them.
